## Доработка Poetry-проекта

Для HTTP-запроса задан тайм-аут 30 секунд.
До чтения JSON вызывается `raise_for_status()`.

Преобразование данных вынесено в функцию `build_dataframe`.
Она получает списки аргументами, возвращает DataFrame
с сортировкой по времени и не обращается к сети.

Скрипт сохраняет `temperature_24h.csv` и `temperature_24h.png`.
Вызов `main` защищён условием `if __name__ == "__main__"`,
поэтому импорт функции не запускает запрос к API.

Тест использует локальные данные и проверяет столбцы, число строк,
порядок времени и соответствие температур после сортировки.

```bash
poetry run python -m pytest -v
poetry run ruff check .
```

Результат: `1 passed`, `All checks passed!`.

## Проверка групп Poetry

Для удаления пакетов исключённых групп использовалась `poetry sync`.

| Команда | Доступен pytest | Доступен Ruff | Основной скрипт |
| --- | --- | --- | --- |
| `poetry sync --only main` | Нет | Нет | Работает |
| `poetry sync --only test` | Да | Нет | Не работает |
| `poetry sync` | Да | Да | Работает |

Основная группа содержит библиотеки программы, поэтому без инструментов
разработки скрипт работает.

Только группа `test` устанавливает `pytest` и его зависимости.
Основные библиотеки не устанавливаются: скрипт завершился с
`ModuleNotFoundError: No module named 'matplotlib'`.
Сбор тестов также завершился ошибкой из-за отсутствия `pandas`.
Это ожидаемо: тестируемой функции нужны зависимости основной группы.

После `poetry sync` восстановлены все группы, тест и программа работают.

## Сравнение подходов

`venv` изолирует окружение, `pip` устанавливает пакеты.
В первой части воспроизводимость обеспечивается Python 3.12
и точными версиями прямых и транзитивных зависимостей
в `requirements.txt`.

Poetry дополнительно хранит прямые зависимости и допустимые диапазоны
в `pyproject.toml`, а точное решение — в `poetry.lock`.
Он управляет группами и согласованностью зависимостей.

Для обоих подходов восстановление проверено в новом окружении.
Запуск основной программы требует доступа к Open-Meteo,
а тест преобразования данных работает без обращения к сети.
